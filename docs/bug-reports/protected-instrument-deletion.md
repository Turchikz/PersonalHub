# Удаление средства измерений с поверкой вызывает ProtectedError

## Предусловия

- Создано средство измерений: «Датчик давления», модель «ЭМИС БАР 143», заводской номер `15207`, функциональный узел `БИК`, статус `ЗИП`.
- Для него создана поверка: дата поверки — сегодня, срок действия — до даты через 365 дней.

## Шаги воспроизведения

1. Отправить `DELETE /api/instruments/{id}/`, где `{id}` — идентификатор созданного средства измерений.

## Ожидаемый результат

API возвращает `409 Conflict` с объяснением, что средство измерений со связанными поверками удалить нельзя. Средство измерений и поверка остаются в базе данных.

## Фактический результат до исправления

При выполнении запроса через `APIClient` тест завершался необработанным исключением `django.db.models.deletion.ProtectedError`. API не формировал предусмотренный ответ `409 Conflict`.

## Причина и исправление

Поле `Verification.instrument` использует `on_delete=PROTECT`: Django запрещает удаление средства измерений со связанной поверкой. В `InstrumentViewSet.destroy()` добавлена обработка `ProtectedError` и ответ `409 Conflict` с сообщением:

> Нельзя удалить средство измерений, для которого существуют поверки.

## Проверка исправления

API-тест `test_delete_instrument_with_verification_returns_409` проверяет код `409 Conflict`, текст ответа и наличие средства измерений в базе после запроса.
